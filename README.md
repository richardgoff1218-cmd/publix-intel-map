## Publix Intel Map – The Villages / Ocala Area

Free, mobile-friendly interactive map for Instacart shoppers.

**Features**
- 15 real Publix stores in the 40-mile radius around Belleview (The Villages, Ocala, Lady Lake, Wildwood, Dunnellon, Belleview)
- Live busyness estimates (grocery-specific time-of-day model)
- Median household income by ZIP (2024 ACS data)
- One-click Google Maps live traffic + Popular Times + Street View
- Add your own stores (geocodes automatically)
- Everything saved locally in your browser

**How to use for an edge**
1. Open the map between batches
2. Look at the "Best right now" panel
3. Position near low-busyness + higher-income stores (especially 32163 in the Villages)
4. Use the traffic buttons for real-time confirmation
